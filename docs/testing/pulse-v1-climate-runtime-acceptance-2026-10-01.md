## Runtime contract closed by this slice

The qualified Climate runtime now owns:

- compact persistent optional Pulse and active-window config with decode/recovery/reconciliation round-trip;
- one execution gate between the Climate parent condition and the existing relay arbiter;
- Shelly one-shot timers for Pulse phases and active-window boundaries;
- Continuous, Cycles and Duration execution, initial delay, ON/OFF start phase, and safe-OFF completion;
- overnight active-window semantics using Shelly local time;
- immediate cancellation on parent inactive, MANUAL takeover, automation fault, hard safety, or active-window close;
- composition with existing minimum ON/OFF and relay debounce rather than a second relay owner;
- compact diagnostics and existing History requested/final relay plus reason-code explanation.

## Still outside this acceptance

- Time + Pulse runtime composition over the existing native Time window model;
- standalone Pulse adapter/runtime;
- Pulse setup/editor UI and responsive/visual acceptance;
- dashboard/detail Pulse status presentation.
